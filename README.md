## About

个人技术博客，记录网络安全研究与软件开发过程中的笔记、Writeup 和学习心得。

- 暗色主题 · 响应式布局 · 移动端适配
- 自动标签检测 · 难度等级徽章
- Markdown 全语法支持（代码高亮、任务列表、折叠面板、脚注等）

## Quick Start

```bash
# 克隆仓库
git clone https://github.com/Jackie1732/Jackie1732.github.io.git
cd Jackie1732.github.io

# 安装依赖 & 本地预览
bundle install
bundle exec jekyll serve
# → http://localhost:4000
```
