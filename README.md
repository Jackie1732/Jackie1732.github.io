个人技术博客，记录安全研究与开发学习笔记。使用 Jekyll + GitHub Pages 搭建，暗色主题，简洁高效。

## 难度标记

文章支持标注难度等级：

```
🟢 Easy  |  🟠 Medium  |  🔴 Hard  |  🟣 Insane
```


## 技术栈

- **框架**: Jekyll (GitHub Pages)
- **样式**: SCSS + Inter + JetBrains Mono
- **部署**: GitHub Actions → GitHub Pages
- **特性**: 自动标签检测 · 难度徽章 · 响应式设计 · 暗色主题
